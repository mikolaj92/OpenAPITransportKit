# ``OpenAPITransportKit``

Alternative `ClientTransport` implementations for clients generated by
`swift-openapi-generator`.

## Overview

OpenAPITransportKit replaces the source of HTTP responses without modifying
generated client code. The generated client still performs request
serialization, response deserialization, status-code handling, and DTO mapping.

Use this package when an app needs to switch between live HTTP, local fixtures,
recorded replay, dynamic responses, or a lightweight stateful backend while
keeping the official `OpenAPIRuntime.ClientTransport` pipeline intact.

This package is not a test framework, not a mock server, and not tied to any
application architecture.

## Requirements

- Swift 6.3 or newer.
- `OpenAPIRuntime` 1.12.0 or newer.
- `HTTPTypes` 1.5.1 or newer.

## Quick Example

```swift
let provider = FixtureResponseProvider(
    loader: MemoryFixtureLoader(fixtures: [
        "getDashboard.success.json": FixturePayload(string: #"{"items":[]}"#)
    ]),
    scenarioProvider: StaticScenarioProvider(.success)
)

let client = Client(
    serverURL: URL(string: "https://example.com")!,
    transport: ProviderTransport(provider: provider)
)
```
